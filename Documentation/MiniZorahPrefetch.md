# MiniZorah 预取与请求尾延迟

日期：2026-09-13。沿用完整 MiniZorah cook、1920×1080、1 GiB 页面池和 1.5 px 质量目标。

本轮从请求回读后的准入等待和细化依赖串行等待入手。新增请求阶段统计、同帧准入和受限的 GPU 预取。页面上传完成后的发布与延迟回收继续使用既有生命周期。

预取额度改为跟随 CPU 剩余容量后，无中途检查运行中的延后尝试仅 4,521 次；先前固定大额度试验中达数十万次。该改动也将试验版最长缺页等待约 328 ms 收紧至 178 ms。运动中需求较少时，`AfterStreamPrefetch` 阶段仍约 0.33～0.39 ms，包含很小的 finalize 成本；固定视角收敛后会停止扫描。

## 实现

- GPU 回读后立即处理当前请求批次，取消原先额外等待一次 `beginFrame` 的准入延迟。根页、当前需求、预取依次占用加载和上传队列；当前需求的屏幕收益/字节排序保留。
- 在实际 frontier、prefix、emit 完成后执行独立的请求阶段。它使用当前视角的 1.0625 倍视锥和 0.95 倍细化阈值，提前寻找视口边缘与下一轮细化页面，允许查询未就绪父级之下的候选。未使用漫游测试的未来相机，也未实现相机速度外推。
- 预取阶段只写请求和去重标记，保持实际 active 状态、cluster mask、驻留状态和间接绘制参数不变。已在内存中的预测页面不会仅因预测而被标记为当前需求。实际 cut 仍要求所有父级 active、页面可绘制，手动 LOD 的行为不变。
- 当前请求先写满自己的槽位，预取只追加至剩余空间，且不超过请求容量的四分之一。GPU 额度进一步取 CPU 可接纳的剩余任务数，额度用完即停止搜索，避免大量反复上报不能准入的预测。请求页号的高位标识预取，64 B 请求头中的三个保留字段变为预取上限、已尝试候选数和丢弃数。CPU 去重时当前需求覆盖预取标识；GPU/CPU 均保留原始页号进行索引。
- CPU 预取按粗层级优先，再按屏幕收益排序。预取不得触发驱逐，不得使已用字节或页面数超过预算的四分之三；未发出、解码中、等待上传的加载任务合计也须低于 `maxPageLoadsInFlight / 4`。剩余容量留给新需求。已提交任务继续完成，过时但尚未发出的任务沿用现有取消规则。
- 相机静止且请求耗尽后停止预取扫描；接近四分之三驻留预算时也停止扫描。视角变化仍会重新触发。默认启用 `lowLatencyRequests`、`prefetchPages` 和 `measurePageLatency`，可分别关闭进行对照。关闭视图需求或屏幕收益排序时同时关闭预取。
- 消费驻留反馈时跳过晚于反馈源帧才发布的页面，避免把“旧帧尚未包含的新页面”误判成已使用的预取。

## 测量口径

`streaming.latency` 提供反馈、准入、I/O 排队、解码、等待上传、上传到可绘制、当前请求到可绘制、预取到可绘制的累计分布，以及未完成/放弃请求数、最老未完成需求年龄。墙钟分位数使用 1 ms 桶，溢出桶采用观测最大值，避免隐藏长停顿；另按 1 帧分桶统计当前请求，超过 2,048 帧时同样保留溢出最大值。

请求起点为对应 GPU 源帧的 CPU 开始时间，因此比 GPU 实际发出请求最多提前一帧工作量。终点为 CPU 将页面发布为 Resident、随后向本帧 GPU 写入页面表的时刻。未绕过队列完成条件来缩短测量值。

预取完成后不再发生缺页请求，剩余请求样本会更集中于冷启动。当前需求与纯预取的完成分布分别统计，不能直接用二者不同样本群的总 P95 宣称提速。`totalPrefetchUsed` 表示预取页面后来收到实际需求，包含上传完成前的提升，不等同于“需求发生时已经命中驻留缓存”。`totalPrefetchDeferred` 统计被延后的尝试次数，包含同页重复尝试。

质量检查运行在转弯前后每 0.25 秒回读实际 cut。这会打断墙钟请求时间，因此该运行用于质量恢复、帧延迟和资源比较。`METALLIC_MINIZORAH_LATENCY_ONLY=1` 只保留结束前的一次检查，不插入截图与中途 cut 回读，用于独立测量墙钟尾延迟。

所有运行均为同步离屏 GPUDriven + MaterialResolve、Vulkan validation、异步 HW/SW，排除呈现 blit。性能分位数排除初始化和检查点验证，不代表编辑器呈现 FPS；文件缓存沿用本机状态，不宣称冷磁盘 I/O 成绩。页面池仍预留 1 GiB，已用字节变化不等于释放同等物理显存。

## 复现

```powershell
$env:METALLIC_TEST_MINIZORAH='1'
$env:METALLIC_MINIZORAH_ROAM_SECONDS='60'
$env:METALLIC_MINIZORAH_ROAM_MIB='1024'
$env:METALLIC_MINIZORAH_PREFETCH='1'
$env:METALLIC_MINIZORAH_LOW_LATENCY='1'
$env:METALLIC_MINIZORAH_TRANSITION_CHECKS='1'
$env:METALLIC_MINIZORAH_LATENCY_ONLY='0'
build-relwithdebinfo/tests/MetallicRhiTests.exe --gtest_filter=RhiRendering.minizorah_roaming --rhi-validation --rhi-async-compute --output-dir build-relwithdebinfo/minizorah-prefetch/repro
```

墙钟延迟对照将 `LATENCY_ONLY` 设为 1，分别运行 `(PREFETCH, LOW_LATENCY)=(0,0)、(0,1)、(1,1)`。固定视角用 `METALLIC_MINIZORAH_FIXED_VIEW=0/15/35`，保留正常检查；持续漫游移除该变量并运行 180 秒。64 MiB 压力场景检查完整回退与预算，不算 1.5 px 质量验收。

原始输出位于 `build-relwithdebinfo/minizorah-prefetch/`。结构化结果与报告哈希见 [MiniZorahPrefetchResult.json](MiniZorahPrefetchResult.json)。
