# 方向光 Mark 有界请求集合覆盖

2026-11-01 按用户决定默认采用。实现直接位于方向光 `vsmMarkRayPages` 的残余扫描分支，无新增运行时或 A/B 开关；局部光、Hard/PCF 路径不变。原有 `markRayPages` 功能配置仍控制整个射线快路径。

复用已计算的 ray/level 范围，以包含原 `lerp + dither`、投影和寻址舍入的误差界扩张，再转换为合法 texel/page 范围。最多枚举四页；只有每页均命中本 lane 的 `lastPages` 或同组已真实发表的完整 page ID，才省略该层 sample 扫描。数值范围不可靠、页数超限或任一查询未命中均保持原扫描。

共享 hash 查询使用原子 OR-zero，不插入推测页。真实标记者的 exchange 后必执行请求 OR，查询只复用这个已有发布承诺；碰撞不能撤销最终请求。候选不新增请求页、共享数组、组 barrier 或全 ray 预扫描。共享存储仍为 1,024 B。

数值证明、独立审查、边界探针和实际运行时 SPIR-V 位于本机 `build/vsm-mark-hash-coverage-20261101/`。未跳过的 sample 路径与基线经 SSA 重命名一致，实际原子查询保留，没有新增 FP→64 位转换。
