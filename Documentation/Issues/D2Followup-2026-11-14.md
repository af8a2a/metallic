## #62 的有界实现

- 新增 [SummarizeTestResults.py](../../Tools/SummarizeTestResults.py)：读取 CTest `--output-junit` / GoogleTest XML，逐 testcase 输出 passed/skipped/failed、明细和 skip 原因直方图；支持 `schemaVersion: 1` JSON。
- failure/error 优先；disabled/notrun/suppressed 归入 skipped，不计 passed。没有 testcase 的输入报错；不靠根节点汇总属性推算已执行用例。
- 退出码：0 无 failed（可有 skip）；1 有 failed，或 `--require-all` 下有 skip；2 参数/输入/解析/报告写入错误。`--require-all` 只控制此工具退出，不改变 runtime harness。
- 输出若与任一输入 XML 解析为同一路径，写前拒绝；覆盖独立已有 JSON 报告仍受支持。
- 新增 [21 项 CPU 回归](../../tests/perf/TestSummarizeTestResults.py)，并在 [CTest 注册](../../tests/CMakeLists.txt#L836-L842) `MetallicTestResultSummaryTests`（`tools;cpu`、30 秒）。用法与粒度限制见 [RHI testbench 说明](../RhiTestbench.md#L33-L58)。
