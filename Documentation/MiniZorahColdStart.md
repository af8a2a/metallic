发现长测的外部负载变化后，又按“新策略→对照”的反向顺序补测同一 60 秒路线，开始、间隔、结束的 GPU 快照分别为 5%、4%、5%。结论未改变：上传平均 51.619→14.898 ms、P95 117→22 ms，请求平均 89.865→66.456 ms、帧 P95 14→11；请求墙钟 P95 仍为 **146→221 ms**、P99 170→253 ms。实际需求样本为 6,958→8,715，GPU P95 9.832→9.521 ms。两组最终没有未完成或丢弃的实际需求。这些快照无法保证运行期间完全隔离其他负载，但也不能把剩余墙钟尾部全部归因于外部程序，仍需直接定位启动长帧。

## 修改

此前上传批次先等待 `max(streamer.queuedFrameCount, residency.queuedFrameCount)` 帧，再排入下一帧的发布任务。即使 GPU 早已完成，页面仍停留在 `PendingUpload`；三个存储/发布任务槽位也继续被占用，阻碍后续批次。

新增 Streamer 上传完成凭据：在暂存页面后取得凭据，在实际记录拷贝的命令上挂接 `SubmissionTransaction`，并关联该帧的 `GpuCompletionPoint`。只有拷贝命令已成功提交且整个批次 GPU 完成，驻留管理器才在下一次 `beginFrame` 直接发布页面，并回收存储及发布槽位。一次处理全部已完成的批次，不再额外排队一帧。检查是非阻塞的，不缩短 GPU 资源复用的帧队列。

必须核对实际拷贝命令：异步 HW/SW 图可能已经提交前面的命令段，却取消了包含拷贝的尾段，此时整个帧的完成点仍可能显示已提交和完成。单独使用帧完成点会错误发布未上传的页面。未 flush、取消、无效录制归属和 Streamer 销毁会取消凭据；页面保留预算内的分配及请求优先级，重新排队上传，锁定根页同样重试。凭据不捕获驻留管理器，管理器重置不会留下悬空回调。

两个流式入口默认开启 `completionDrivenUploads`。未使用 `Streamer::beginFrame(RenderFrameContext&)` 的旧调用者保留原来的帧延迟协议；开关也保留用于 A/B 对照。新增 `totalCompletionDrivenUploads` 与 `totalCancelledUploads` 统计，以确认实际启用和取消路径。

## 测量口径

每轮重新启动进程、重新建立 GPU 驻留。使用既有 cook 和 shader 缓存，未清空操作系统文件缓存，因此这里的冷启动指 GPU 页面工作集建立，不代表物理磁盘冷缓存测试。两组均启用同帧准入和受限预取，只切换上传发布策略。

延迟组仅在结束前读取一次完整性及累计延迟统计，不穿插 PNG 和 cut 检查。固定视角 10 秒用于集中观察初始工作集；60 秒使用既有近远切换路线。质量组另行进行密集检查，记录首个可见误差超标归零点，其墙钟时间包含检查开销。`LATENCY_ONLY=1` 的末次检查不能用于声称首次收敛时间。

请求起点沿用 GPU 源帧的 CPU 开始时间，近似误差最多包含该帧工作；分位数为 1 ms 桶的上界。加快发布会改变预取与实际需求的归类，必须同时报告完成请求数量、上传样本量、未完成请求与资源总量。根页就绪墙钟包含首次图/PSO 初始化，不能将其全部差异归因于上传策略。

## 验证与复现

三个固定视角分别在约 1.005、1.001、1.002 秒的检查点达到目标，末次可见误差最大值为 1.499921、1.499972、1.499958 px。固定近景 `fixed-15/roam-5.png` 与前序质量基准 `minizorah-quality/fixed-near/roam-25.png` 的 SHA-256 完全相同：`b181ca6e019e5d95a28f7857054de6fdc80b00aa066d0fb871302122f3344f75`。

新增完成凭据回归覆盖：GPU 被 timeline gate 延迟 16 个 CPU 帧仍不提前发布、完成后下一帧直接可绘制、未 flush 丢弃、取消命令、只提交前缀后取消拷贝尾段、录制归属不匹配、普通需求与根页重试、一次回收三个完成批次、管理器重置与 Streamer 销毁。实际拷贝内容同时与原页面字节比较，旧的无完成点帧延迟协议继续由原回归覆盖。

- 180 秒：13,108 个计时帧、36 个检查点；60～175 秒的 24 个检查点均无可见超标，末次页面池 671.950 MiB、上传 701.757 MB、驱逐和取消均为 0。GPU P95 为 19.070 ms、同步帧 P95 为 29.381 ms。
- 64 MiB、60 秒：末次使用 61.949 MiB、上传 205.474 MB、驱逐 12,207 页；没有无效 GPU 请求、页面加载错误和意外取消。完整回退通过，但末次仍有 3,631 个可见超标 refinement，**不算 1.5 px 质量验收**。
