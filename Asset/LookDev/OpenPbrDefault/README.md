# MaterialX OpenPBR default LookDev

Load **LookDev / OpenPBR Default** from the editor's **Built-in Sample** selector.
See [the LookDev guide](../../../Documentation/OpenPbrLookDev.md) for framing,
lighting, display settings, capture commands and comparison limits.

The glTF loads its adjacent `OpenPbrDefault.metallic_scene.json` automatically.
Keep the glTF, `Shaderball.bin`, scene sidecar and HDRI together.

[AcademySoftwareFoundation/MaterialX](https://github.com/AcademySoftwareFoundation/MaterialX).
`Reference.json` records immutable source URLs and SHA256 checksums. The public
[MaterialX Web Viewer](https://academysoftwarefoundation.github.io/MaterialX/?file=Materials/Examples/OpenPbr/open_pbr_default.mtlx)
is the visual reference.

`Shaderball.bin` is the unchanged binary mesh chunk of `resources/Geometry/shaderball.glb`.
`OpenPbrDefault.gltf` changes the source material to the values in
`open_pbr_default.mtlx`, adds the viewer's fitted camera and removes unused
`FB_ngon_encoding` annotations from the already triangulated meshes. Vertex
positions, authored normals, UVs and triangle indices are unchanged.

The HDRI and both MaterialX documents are unmodified upstream files. The scene
sidecar and render graph are Metallic configurations, generated by
`Tools/BuildOpenPbrLookDev.py`. No MaterialX runtime dependency is required to
open this scene; this is an explicit mapping of the default material, not a
general MaterialX importer.
